## Getting Started

### Prerequisites

- Python 3.8 or higher
- pip package manager

### Installation

1. Clone this repository:
```bash
git clone git@github.com:TIH233/ISYE6202_WarehousingCaseworks.git
cd ISYE6202_WarehousingCaseworks
```

2. Create and activate the virtual environment:
```bash
# Create virtual environment
python3 -m venv venv

# Activate on Linux/Mac
source venv/bin/activate

# Activate on Windows
venv\Scripts\activate
```

3. Install required packages:
```bash
pip install -r requirements.txt
```

## Dependencies

This project uses the following main packages:
- **PuLP**: Integer and linear programming optimization
- **NumPy**: Numerical computing
- **Pandas**: Data manipulation and analysis
- **openpyxl**: Excel file handling
- **SciPy**: Scientific computing
- **Matplotlib/Seaborn**: Data visualization
- **Jupyter**: Interactive notebooks for analysis

See [requirements.txt](./requirements.txt) for the complete list with versions.
